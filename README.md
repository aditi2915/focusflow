# FocusFlow 🎯
### Turn Deadlines into Done.

FocusFlow is a simple, student-focused study planner that helps students organize their academic tasks, prioritize important work, and manage deadlines without unnecessary distractions.

🔗 **Live Demo:** https://quiet-sunshine-4f006d.netlify.app

## ✨ Features

- 📝 **Task Management** — Add and manage study tasks in one place.
- 🎯 **Priority Levels** — Identify important tasks and decide what to tackle first.
- 📅 **Deadlines** — Keep track of upcoming assignments and study goals.
- 🔍 **Search & Filter** — Find tasks and organize them easily.
- ↕️ **Sorting** — Arrange tasks to make planning more convenient.
- 💾 **Local Storage** — Keep tasks saved in your browser even after refreshing.
- 📱 **Responsive Design** — Use the planner across different screen sizes.

## 🛠️ Built With

- **HTML** — Page structure
- **CSS** — Styling and responsive layout
- **JavaScript** — Task management and interactive features
- **Local Storage** — Browser-based data persistence

## 🚀 Getting Started

You can run FocusFlow locally without installing additional dependencies.

1. Clone this repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project folder:

   ```bash
   cd focusflow
   ```

3. Open `index.html` in your browser.

Alternatively, use a local development server:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## 💡 Problem It Solves

Students often struggle to balance assignments, deadlines, exams, and daily study goals. FocusFlow brings essential planning tools into one lightweight application, helping students stay organized and focus on what matters most.

## 🌟 What Makes FocusFlow Different?

FocusFlow prioritizes simplicity. Instead of overwhelming students with complicated productivity tools, it offers an accessible way to organize tasks, recognize priorities, and stay on track.
